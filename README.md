# Interior Studio

A modern, elegant interior studio website designed with a clean and premium visual aesthetic.

## 1. Selected Colour Palette

| Purpose                  | Colour                | Hex Code  |
| ------------------------ | --------------------- | --------- |
| **Primary / Background** | Clean White           | `#FFFFFF` |
| **Secondary Background** | Light Grey            | `#F8F9FA` |
| **Typography / Headers** | Deep Charcoal / Black | `#1A1A1A` |
| **Accent Colour**        | Premium Gold          | `#B9935A` |

### Colour Usage

* **Clean White (`#FFFFFF`)** and **Light Grey (`#F8F9FA`)** are used for an open, airy, and minimal feel.
* **Deep Charcoal / Black (`#1A1A1A`)** is used for typography and headings to provide strong, readable contrast.
* **Premium Gold (`#B9935A`)** is used as the accent colour for icons, hover states, and selected buttons to create a sophisticated and luxurious appearance.

---

## 2. Selected Fonts

### Headings

**Serif Font**

A classic and elegant serif typeface is used for headings to complement the high-end interior design aesthetic.

### Body Text

**Inter**

A highly legible and modern sans-serif font that pairs well with the decorative headings while maintaining readability across all screen sizes.

---

## Design Philosophy

The website follows a **minimal, elegant, and premium interior design aesthetic**, combining:

* Clean and spacious layouts
* Neutral backgrounds
* Strong charcoal typography
* Premium gold accents
* Elegant serif headings
* Modern sans-serif body text
* Responsive design across different screen sizes
* Smooth and interactive testimonial sliders

The overall visual direction focuses on creating a **luxurious yet approachable experience** suitable for a high-end interior design studio.
